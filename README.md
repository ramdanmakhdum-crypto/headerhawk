# HeaderHawk


CLI & API untuk scan security header website dan memberikan skor keamanan.


## Fitur
-scan security headers (CSP, HSTS, X-Frame-Options, dll)
-Output tabel + skor A-F
-Expert JSON

## Tech Stack
-Python (httpx, typer, rich)
-FastAPI (API)
-Next.js (Web UI - coming soon)
